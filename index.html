01. About me

I’m a Computer Science student at California State University Fullerton, graduating 2028, currently working through backend development, machine learning, compilers, and operating systems coursework.

I chose Computer Science because I'd been playing video games my whole life and it seemed like the natural fit, but there wasn't much passion behind it at first. That changed in Data Structures and Software Engineering. Somewhere in those courses I started looking at everything — online and in the real world — and wondering how it was built. How does a medical device actually run? When I use a website, where does that data go, how is it stored, what structures and algorithms make it feel fast?

I haven't stopped asking that question since, and that curiosity is why I'm so drawn to full-stack and product engineering. I want to understand the whole system, not just a layer of it.

Outside of code I enjoy spending time with my friends, going to the gym, and snowboarding at Big Bear Mountain. I also have hit top 500 in Overwatch.

03. Projects

Things I’ve built, and what was actually interesting about building them.

Featured

September 2026

Internship Application Tracker

A local-first tracker that keeps every application in the browser with no backend at all. The whole UI runs through a single render function driven by array state, so the DOM stays in sync on every edit — status changes, filtering, and column sorting included.

  • Companion Rust CLI over a normalized SQLite schema, sharing one JSON format with the web client
  • JSON import/export so the data is never trapped in one of the two
  • GitHub Actions builds and publishes the static site on every push to main
  • JavaScript
  • Rust
  • SQLite
  • GitHub Actions

April 2026

Zombie OverFlow

An educational math game in Python, split across 7 modules that keep gameplay, auth, economy, and data cleanly separated.

  • 3-table SQLite schema with foreign keys, unique constraints, and multi-table JOINs
  • Registration, login, security-question recovery, and profile updates over parameterized SQL
  • Persistent currency with difficulty-based multipliers and duplicate-reward prevention
  • 13 unit tests covering earning, spending, boundary, and invalid-input cases
  • Python
  • SQLite
  • SQL
  • unittest

May 2025

Dinosaur Database

A working record database in C++ built on a binary search tree I wrote myself, rather than anything off the shelf.

  • Insertion, deletion, traversal, and search implemented from scratch
  • A Dinosaur class with operator overloading, so comparison and sorting fall out naturally
  • Text-based UI for interactive manipulation, plus AVL tree visualization through Graphviz
  • C++
  • BST / AVL
  • Graphviz
